# Proyecto final para taller de Git y GitHub

Proyecto realizado para el taller de Git y GitHub.
La implementación de todo lo documentado se presenta en respuesta al proyecto final solicitado por **Taller de GIT y GITHUB - UNAHUR**.

**Repositorio oficial del grupo "Mythic Byte" para presentación Taller de Git y GitHub**.

Este repositorio contiene resultado de las practicas realizadas durante la cursada.

---

## ¿Cómo se trabaja en nuestro?

Este es un **grupo de desarrollo teórico/practico**.

La mayor parte de lo aprendido y desarrollado fue mediante sobre repositorios de prueba privados y actividades practicas.

El trabajo se gestiona de esta manera:

```text
Concepto
   ↓
Practica
   ↓
Problema
   ↓
Desarrollo
   ↓
Error
   ↓
Resolución
   ↓
Comprensión
```

Muchos de nuestro errores se solucionan entre nosotros, lo que brinda una mejor comprensión de los mismos.
